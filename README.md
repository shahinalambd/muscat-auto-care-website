# Muscat Auto Care Website

A bright, modern multi-page website concept for a car wash and detailing studio in Muscat, available in English and Arabic.

## Live preview

https://shahinalambd.github.io/muscat-auto-care-website/

## Key features

- 8 pages in English plus a complete Arabic (RTL) version, with a one-click language switch
- Hero slider and interactive before/after comparison slider
- Filterable gallery with lightbox
- Pricing tables and a dynamic service details page (`service-details.html?service=<slug>`)
- Booking and contact forms with client-side validation and a summary screen
- Motion details: 3D tilt, magnetic buttons, parallax and page transitions (reduced-motion aware)
- Responsive WebP images in two sizes, SEO meta and JSON-LD structured data

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- No build step, so the site runs as plain static files

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- All contact details are placeholders (`+000 0000 0000`, `hello@example.com`).
- Forms are static demos: they validate input but do not send any data.
